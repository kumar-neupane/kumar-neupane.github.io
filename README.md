# kumar-neupane.github.io

Personal portfolio website for Kumar Neupane, PhD candidate in Physics at Michigan Technological University.

🔗 **Live Site**: [https://kumar-neupane.github.io](https://kumar-neupane.github.io)

## About

This website showcases my research, publications, projects, and achievements in the field of physics, with a focus on nanotechnology, transition metal dichalcogenides (TMDCs), and renewable energy applications.

## Features

- **Home**: Introduction and overview of research interests
- **Publications**: Comprehensive list of research papers and academic contributions
- **Projects**: Showcase of research projects and technical work
- **Achievements**: Academic awards, participations, and recognitions
- **Blog**: Thoughts and insights on physics and research
- **Dark/Light Mode**: Toggle between themes for comfortable viewing
- **Responsive Design**: Optimized for desktop and mobile devices
- **Contact Form**: Easy way to get in touch

## Technologies Used

- **Jekyll**: Static site generator
- **HTML5 & CSS3**: Modern web standards
- **JavaScript**: Interactive features and dynamic content
- **GitHub Pages**: Hosting platform
- **Font Awesome**: Icon library
- **Google Fonts**: Typography (Inter font family)

## Local Development

To run this website locally:

### Prerequisites
- Ruby (version 2.5 or higher)
- Bundler gem

### Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/kumar-neupane/kumar-neupane.github.io.git
   cd kumar-neupane.github.io
   ```

2. Install dependencies:
   ```bash
   bundle install
   ```

3. Run the Jekyll server:
   ```bash
   bundle exec jekyll serve
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:4000
   ```
